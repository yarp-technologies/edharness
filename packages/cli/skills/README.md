# Bundled skills

These skills are included in the CLI distribution and are copied to
`~/.agents/skills` by the installer when neither the standalone `skills` CLI
nor `npx` is available.

Sources:

- [anthropics/skills](https://github.com/anthropics/skills)
- [obra/superpowers](https://github.com/obra/superpowers)
- [yarp-technologies/opened-skill](https://github.com/yarp-technologies/opened-skill/tree/983693a866a64205913f81c6e440aa36a4a63791)

The selected skill names are kept in the installer so the remote and bundled
installation paths remain aligned.
